# EcuaData - Ecuadorian Election Data Visualization & Analysis (WIP)
Project that visualizes and analyzes Ecuadorian election data from 2023 and 2025, generated by a ETL data pipeline. 
## Currently At...
Minimum Viable Product (MVP):
* Loaded csv with election data into a pandas dataframe. Dataframe is loaded into plotly where visualizations (pie and bar charts) are generated.
